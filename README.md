## 🚀 Features Covered

### 1. Numeric Data Types
Demonstrates standard numeric data types in Python:
* **Integer (`int`)**: Whole numbers e.g., `10`
* **Floating-Point (`float`)**: Decimal numbers e.g., `3.14`
* **Complex (`complex`)**: Numbers with real and imaginary parts e.g., `3+2j`

```python
x = 10       # int
y = 3.14     # float
z = 3 + 2j   # complex
```

### 2. Arithmetic Operations
Covers basic and advanced mathematical calculations:
* Addition (`+`), Subtraction (`-`), Multiplication (`*`)
* Floating-point division (`/`), Floor division (`//`)
* Modulus / Remainder (`%`), Exponentiation (`**`)

### 3. Comparison Operators
Evaluates expressions returning boolean values (`True` or `False`):
* Equal (`==`), Not equal (`!=`)
* Less than (`<`), Greater than (`>`)
* Less than or equal to (`<=`), Greater than or equal to (`>=`)

### 4. Logical Operators
Combines conditional statements:
* `and`: Returns `True` if both conditions are true.
* `or`: Returns `True` if at least one condition is true.
* `not`: Inverts the boolean output.

### 5. Mathematical & Rounding Functions
Utilizes Python's built-in `round()` and the `math` module:
* `math.ceil()`: Rounds a number up to the nearest integer.
* `math.floor()`: Rounds a number down to the nearest integer.
* `round()`: Rounds a floating-point number to the nearest integer.

### 6. Python Lists & Data Collections
Demonstrates creating and manipulating dynamic arrays (lists):
* **Data Heterogeneity**: Homogeneous lists (integers, strings, booleans) and mixed data lists.
* **Element Indexing**: Accessing elements via zero-based indexing (`data[1]`).
* **List Operations & Methods**:
  * `.append()`: Add elements to the end.
  * `.remove()`: Remove first occurrence of a specified item.
  * `.pop()`: Remove and return item at specified index.
  * `len()`: Retrieve list length.
  * `in`: Check membership/existence of an item.
  * `.sort()`: Sort items in ascending order.
  * `.reverse()`: Reverse current list order.
